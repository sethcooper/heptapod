## Failure cases and fixes

The original wrapper ignored a supplied UFO when generating diagrams. The fixed
wrapper binds `Model.from_ufo` explicitly. A synthetic `s -> x x` model regression
checks this without relying on SM particle aliases. Moving that UFO preserves its
model fingerprint and process identity.

The initial repeated MG validation test exposed Python UFO module caching across
scratch directories. Scratch models now have distinct import names; agent-facing
calls also run in separate subprocesses. Mutation tests reject a removed process
and an incorrect signed vertex PDG assignment. Invalid paths/models do not fall
back to the SM. Budget failure and timeout tests retain failed receipts; existing
output directories cannot be overwritten.

The initial tiny UFO test fixture lacked `coupling_orders.py`; it was corrected
to provide the required declaration. Agent wrappers implement Orchestral's
`_run` hook and were tested by actual instantiation and subprocess execution.

MG5 emits Python 3.13 deprecation/syntax warnings in its own sources. The tested
operations completed successfully. This record does not establish compatibility
on a second OS, validate numerical widths, or certify arbitrary BSM UFOs.
